# Как открыть портфолио

Короткая памятка, если вы смотрите Кирилла Ивахненко.

## Ссылка

[https://koshalabeck.github.io/portfolio/](https://koshalabeck.github.io/portfolio/)

Это GitHub Pages из репозитория [Koshalabeck/portfolio](https://github.com/Koshalabeck/portfolio). Страница выкладывается workflow при пуше в ветку `main`.

Один раз в настройках репозитория нужно выбрать источник Pages: **Settings → Pages → Build and deployment → Source: GitHub Actions**. Пока источник не выбран, ссылка не откроется. Это настройка репозитория, не поломка самой страницы.

## Что на странице

Сайт на русском. В шапке кнопки **RU / EN**.

1. **Первый экран.** Имя, Москва, Московский Политех, кнопки «Проекты» и GitHub, кадр магазина iForm. Отдельная плашка: изучаю Go.
2. **Обо мне.** 2005 год, Чита, переезд в Москву в 2023, учёба в Политехе, фраза «обучаюсь в Яндекс Практикуме», Т-Банк, языки, ценности.
3. **Навыки.** Стек и честная строка «изучаю Go» (дорожная карта к стажировке в Яндексе, без коммерческого опыта). Рядом практика с техникой, Blender и то, как Кирилл работает.
4. **Проекты.** iForm со скриншотами: главная, каталог, товар, корзина, компьютер и телефон. Дальше гайд по iPod nano 7, форк webview-shell-ios и пет-проекты со старой страницы.
5. **Опыт.** Учёба, Практикум, Go, Т-Банк, магазин, медиа, тендеры, студенты. Рядом блок про безопасность.
6. **Что ищу.** Сильная команда, интерес к Яндексу и VK.
7. **Связь.** GitHub, Telegram, VK, X, Steam и почта [kivahnenkok@gmail.com](mailto:kivahnenkok@gmail.com).

## С телефона

Та же ссылка. Меню открывается кнопкой справа. Текст в одну колонку. У iForm можно переключить кадр «Телефон».

## Если ссылка не открылась

1. Откройте [github.com/Koshalabeck/portfolio](https://github.com/Koshalabeck/portfolio).
2. Зелёная кнопка **Code** → **Download ZIP**.
3. Распакуйте архив.
4. Откройте файл `index.html` двойным щелчком в Chrome, Safari, Edge или Firefox.

Для самой страницы интернет не нужен. Ссылки на GitHub и мессенджеры откроются, когда сеть есть.

# How to open the portfolio

A short note if you are reviewing Kirill Ivakhnenko.

## Link

[https://koshalabeck.github.io/portfolio/](https://koshalabeck.github.io/portfolio/)

The site is GitHub Pages for [Koshalabeck/portfolio](https://github.com/Koshalabeck/portfolio). A workflow publishes it on every push to `main`.

Once, in the repository settings, choose the Pages source: **Settings → Pages → Build and deployment → Source: GitHub Actions**. Until that source is selected, the link will not open. That is a repository setting, not a broken page.

## What you will see

The page opens in Russian. **RU / EN** sits in the header.

1. **First screen.** Name, Moscow, Moscow Polytech, buttons for projects and GitHub, and a frame of the iForm store. A separate note says he is learning Go.
2. **About.** Born in 2005, grew up in Chita, moved to Moscow in 2023, Polytech, the modest line “studying at Yandex Practicum”, T-Bank, languages, values.
3. **Skills.** The stack, with an honest “learning Go” (a roadmap toward a Yandex internship, not commercial experience). Practical device help, Blender, and how he works.
4. **Projects.** iForm with screenshots: home, catalog, product, cart, desktop and phone. Then the iPod nano 7 guide, the webview-shell-ios fork, and pet projects from the previous page.
5. **Experience.** Studies, Practicum, Go, T-Bank, the store, media, tenders, students. A security block sits beside it.
6. **What he is looking for.** A strong team, interest in Yandex and VK.
7. **Contact.** GitHub, Telegram, VK, X, Steam, and email [kivahnenkok@gmail.com](mailto:kivahnenkok@gmail.com).

## On a phone

Same link. The menu is the button on the right. Text stacks in one column. On iForm, switch the shot to “Phone”.

## If the link does not open

1. Open [github.com/Koshalabeck/portfolio](https://github.com/Koshalabeck/portfolio).
2. Green **Code** button → **Download ZIP**.
3. Unzip the archive.
4. Open `index.html` with a double-click in Chrome, Safari, Edge, or Firefox.

The page itself does not need a network. GitHub and messenger links open when you are online.
