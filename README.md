# Портфолио Кирилла Ивахненко

Личная страница: Московский Политех, Яндекс Практикум, магазин iForm и пет-проекты. На странице русский и английский. В навыках честно отмечено: изучаю Go.

![Первый экран портфолио](assets/readme-preview.jpg)

Как открыть сайт, что на нём по разделам и что делать, если ссылка не открылась: [HR_GUIDE.md](HR_GUIDE.md).

Живая страница: [https://koshalabeck.github.io/portfolio/](https://koshalabeck.github.io/portfolio/)

Она появится после того, как в настройках репозитория один раз выбрать источник Pages: **GitHub Actions**. Пуш в `main` выкладывает сайт workflow-файлом `.github/workflows/pages.yml`.

Локально достаточно открыть `index.html`.
